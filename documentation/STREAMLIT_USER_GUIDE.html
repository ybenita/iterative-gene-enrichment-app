1. Overview

The Streamlit web interface provides an interactive way to perform gene enrichment analysis. Features include:

  • Two Analysis Modes — Regular (standard ORA) and Iterative (iGEA)
  • 12 Gene Set Libraries — MSigDB v2025.1 collections (H, C2, C5) plus Protein Interaction
  • Real-time Visualization — Ranked bar charts, interactive tables, network graphs
  • Network Visualization — Generate network graphs for conversational AI systems
  • Statistical Benchmarking — Compare results against random gene lists
  • Custom Backgrounds — Upload your own background gene list
  • Multiple P-value Methods — Fisher's Exact Test, Hypergeometric, Chi-squared

2. Getting Started

Accessing the App

The app is deployed on Streamlit Community Cloud. Open the shared URL in any modern browser — no installation required.

Interface Layout

  1. Sidebar — Mode selection (Regular / Iterative), app information, documentation link
  2. Analysis Tab — Input area, library selection, parameters
  3. Advanced Settings Tab — P-value method, background selection, custom upload
  4. Results Area — Tables, charts, downloads (appears after analysis)

3. Input Methods

Method 1: Direct Input

  1. Select Input Format: Gene Symbols or Entrez IDs
  2. Paste genes into the text area (one per line, max 800)
  3. Name your gene set in the "Input/edit gene list name" field
  4. Click Submit

Method 2: File Selection

Use the "Or select a file from the data folder" dropdown to pick a pre-loaded .txt gene list.

Method 3: Load Example

Click Load Example to populate the input with a sample gene set (HIV dependency factors).

Gene Input Validation

The app automatically:

  • Converts Entrez IDs → official gene symbols
  • Updates old symbols → current symbols
  • Removes duplicates
  • Validates against the background gene list
  • Displays conversion statistics and unrecognized genes
Limits: Minimum 20 genes, maximum 800 genes for optimal performance.

4. Analysis Modes

Regular Mode

Standard one-pass over-representation analysis (ORA). Tests your gene set against all selected libraries, calculates enrichment statistics, and filters by p-value thresholds. Includes FDR adjustment.

Best for: comprehensive overview of all significant pathways.

Iterative Mode

Iteratively removes genes from the top hit at each step:

  1. Finds the top enriched term (lowest p-value)
  2. Removes overlapping genes from your input
  3. Repeats until no terms pass the threshold or max iterations reached
  4. Builds a gene–term network integrating results across libraries

Best for: LLM-assisted interpretation and network visualization of enrichment results.

6. Understanding Results

Regular Mode Results

  • Results Table — Term name, p-value, adjusted p-value, overlap (X/Y), genes
  • Bar Chart — -log10(p-value) on x-axis, interactive (hover, zoom)
  • Library Info — Gene count (library-specific input / total), background count

Iterative Mode Results

  • Iteration Table — Results organized by iteration number
  • Network Visualization — Interactive graph showing pathway relationships
  • ORA vs iGEA Comparison — Statistics comparing Iteration 1 vs all iterations
  • Statistical Benchmarking — Z-scores and percentiles vs random gene lists

Interpreting Benchmarking

Z-score Percentile Interpretation
> 2.0 > 95% ✓✓ Significantly better (top 5%)
> 1.0 > 84% ✓ Better (top 16%)
≈ 0.0 ≈ 50% ~ Similar to random
< -1.0 < 16% ✗ Worse than random

Iterative Mode

8. Advanced Features

Custom Background Gene List

  1. Go to the Advanced Settings tab
  2. Select format: Gene Symbols or Entrez IDs
  3. Click "Upload your background gene list"
  4. Select a .txt file (one gene per line)
  5. Click "Apply Settings"
Cloud note: Uploaded backgrounds are ephemeral — they persist only for the current session.

Network Generation (Iterative Mode)

  1. Run an iterative analysis
  2. Check "Use results in network" for each library
  3. Click "Generate Network"
  4. View the interactive Plotly graph
  5. Copy the generated prompt for use with AI systems (ChatGPT, Claude, etc.)

Statistical Benchmarking (Iterative Mode)

Runs automatically after iterative analysis. Compares your network metrics against thousands of random gene lists using pre-computed permutation data.

  • Metrics: cluster size, edges, connectivity, library diversity
  • Permutation data available for gene list sizes 50–1000 (increments of 50)
  • Download the full statistical report

9. Troubleshooting

"No enrichment results found"

  • Increase p-value threshold (try 0.05)
  • Reduce minimum overlap to 1 or 2
  • Expand term size range (e.g., 5–1000)
  • Try different libraries

"Gene validation failed"

  • Check gene spelling and format
  • Verify the correct input format is selected (Symbols vs Entrez IDs)
  • Ensure at least 20 validated genes

App is slow or unresponsive

  • Reduce gene list size (stay under 500 genes)
  • Select fewer libraries
  • Reduce max term size
  • Refresh the browser

Benchmarking not available

  • Only available in Iterative mode
  • Requires gene list sizes between 50–1000
  • Best results with default parameters (min overlap 3, term size 10–600)

10. Best Practices

Input Preparation

  • Use official HGNC gene symbols when possible
  • Remove duplicates before input
  • Keep lists between 20–800 genes
  • Use descriptive gene set names

Analysis Strategy

  1. Start with Regular Mode for a quick overview
  2. Default libraries (Hallmark, Reactome, GO BP) are pre-selected
  3. Switch to Iterative Mode for network visualization
  4. Download results for record-keeping

Result Interpretation

  • Focus on highly significant results (p < 0.01)
  • In Regular mode, FDR < 0.05 is the standard significance threshold
  • Check that overlap sizes are biologically meaningful
  • Compare results across libraries for consistency

11. Cloud-Specific Notes

Ephemeral Storage: Streamlit Community Cloud uses ephemeral storage. Results and uploaded files are temporary and will be lost when the app restarts. Always download your results before closing the browser.
Performance: The Cloud edition uses cached data loading — gene info, libraries, and backgrounds are parsed once and reused across interactions. First load may take a few seconds; subsequent runs are faster.
Feature Cloud Behaviour
Results storage Stored in /tmp/ — ephemeral, download immediately
Custom backgrounds Persist for current session only
Data caching GMT files, gene info, and backgrounds cached via @st.cache_data
Libraries 12 active MSigDB v2025.1 libraries
Benchmarking data Pre-computed parquet statistics (sizes 50–1000)
